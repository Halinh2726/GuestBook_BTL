# GuestBook_BTL

Project gồm hai phiên bản độc lập:

| Thư mục | Mô tả | Cổng mặc định |
| --- | --- | --- |
| `handwriting/` | Bản code thủ công ban đầu, giữ nguyên giao diện và tính năng hiện có. | `5000` |
| `vibe-coding/` | Bản thiết kế lại chất lượng cao theo phong cách editorial hiện đại. | `5001` |

## Chạy một phiên bản

```bash
cd handwriting       # hoặc: cd vibe-coding
pip install -r requirements.txt
python app.py
```

Mỗi thư mục có `README.md`, `app.py`, `data.json`, `templates/` và `static/` riêng nên có thể chạy, chỉnh sửa hoặc nộp bài độc lập.
